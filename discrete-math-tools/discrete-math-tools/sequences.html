Sequences and series

    Find r or d from two neighbouring terms

    Notes

    In a geometric sequence every term is the previous one times a common ratio r. In an arithmetic sequence every term is the previous one plus a common difference d.

    geometric: a(n) = afirst · rn − first index
    arithmetic: a(n) = afirst + d · (n − first index)

    Adding up N terms, where N = n − first index + 1:

    geometric: S = a · (1 − rN) / (1 − r), or N · a when r = 1
    arithmetic: S = N · (first term + last term) / 2

    An infinite geometric series adds up to a number only when |r| < 1. Then the terms shrink toward 0 and the sum is:

    S = a / (1 − r)

    When |r| ≥ 1 the sum has no finite value, so the tool says it diverges instead of plugging into the formula. The formula would give a meaningless number there, for example −1 for a = 1 and r = 2.

    Multiplying by (−1)n flips the sign of every other term, which is a quick way to make a sequence alternate.

    The last calculator works backward: two neighbouring terms give r by dividing the second by the first, and d by subtracting the first from the second.
