Row reduction

Enter a matrix, or the coefficients of a system of equations. You get echelon form, reduced echelon form, the rank, the solution, and every row operation along the way.

The default is x₁ + x₂ + x₃ = 6, 2x₁ − x₂ + x₃ = 3, x₁ + 2x₂ − x₃ = 2. Type in the cells, move with the arrow keys, or paste a block of cells copied from Excel. Blank cells count as 0.

Notes

Row reduction uses three moves that never change the solutions of a system: swap two rows, multiply a row by a number other than 0, and add a multiple of one row to another.

The forward phase builds echelon form. Working left to right, it picks a pivot in each column, scales that row so the pivot is 1, and clears every entry below it. The backward phase works from the bottom pivot upward, clearing the entries above each pivot, which gives reduced echelon form.

The rank is the number of pivots. For a system with n unknowns:

  • If the right-hand column holds a pivot (a row like 0 0 0 | 1), the system has no solution.
  • If every unknown has a pivot, the solution is unique.
  • Otherwise the unknowns without a pivot are free, and the system has infinitely many solutions.

Row operations are written like R2 ← R2 − 3·R1, which reads "replace row 2 with row 2 minus 3 times row 1", and R1 ↔ R2 for a swap.
