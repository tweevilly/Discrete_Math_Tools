Determinant and inverse

    Notes

    A matrix with m rows and n columns can be multiplied by one with n rows and p columns. The answer has m rows and p columns. The inner sizes have to match.

    (AB)ij = ai1b1j + ai2b2j + … + ainbnj

    Each entry of the answer is a row of A multiplied term by term with a column of B, then added up. The line under the first calculator spells out the first entry.

    For a 2 × 2 matrix with entries a, b in the top row and c, d in the bottom row:

    det A = ad − bc    A−1 = 1/(ad − bc) · [ d −b ; −c a ]

    If det A = 0, the matrix has no inverse. For larger sizes, the tool finds the inverse by row reducing A next to the identity matrix (Gauss–Jordan), and it checks the answer by multiplying A by A−1 to get the identity back.
